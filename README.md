Aerospace engineer at Bell. Outside of work I like to make cool things, from harnesses to hardware.

- [nstack](https://github.com/nategriffin26/nstack): my ever-evolving set of agent rules, skills and tools
- [mlx-resin](https://github.com/nategriffin26/mlx-resin): Resin's inference engine on Apple Silicon, with per-request neuron steering
- [Steppotron](https://github.com/nategriffin26/singing-motors): plays any song from a MIDI file on 6 stepper motors, driven by an ESP32
- [Strain-wave drive](https://github.com/nategriffin26/strain-wave-drive): 3D-printed harmonic drive built around a NEMA 23 motor, from parametric CadQuery source
